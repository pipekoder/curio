# Reset Demo Usage

When `DEMO_TESTING_MODE=true`, the authenticated Content Studio shows current operator budget status and a **Reset Demo Usage** action. The action requires the existing catalog operator Bearer token, the same-origin request check, and an explicit confirmation in the browser. The server derives the operator IP from `CF-Connecting-IP` and validates any Demo Tester session from the existing IP-bound HttpOnly cookie. The browser cannot supply an IP or tester ID.

`POST /api/operator/catalog/intelligence/budget/reset-demo` clears only the current operator IP's hourly and cooldown counters. If this request carries a valid Demo Tester session, it also clears that tester's current hourly and fixed 15-minute window counters. When Article Preparation is enabled, it clears this IP's preparation hourly and short-window counters. The Durable Object performs these deletes and a persistent `demo_reset_events` audit insert in one SQLite transaction in the existing `magazine-v1` instance. There is no D1 migration or new Durable Object binding.

The action does not touch shared lifetime or daily counters, tester daily or preparation daily counters, SAM once-per-asset history, reservation events, active leases, or Article Edition jobs. A reset does not refund Meta calls. The response reports whether a shared daily or lifetime cap still prevents another four-unit request, and the UI refreshes the protected status endpoint before showing success. A user without a Demo Tester session can reset only the current operator IP limits; it does not create a tester session.

The existing rate limiter is IP-based. Users sharing the operator's network IP share that IP counter, so resetting it may also restore another user on the same public IP. A different IP and any other tester-specific window are unaffected. The operator must use this action only during controlled testing. The global daily/lifetime caps and two active tester leases remain authoritative.

The button is hidden when the toggle is off or status cannot be read. Server-side authorization also rejects the action when the toggle is off, even if a stale page still shows the button. To disable the action immediately, set `DEMO_TESTING_MODE=false` through the existing Cloudflare settings process. No deployment, counter reset, or provider call is required to use the button once this code is approved and deployed.
