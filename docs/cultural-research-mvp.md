# Default-off cultural source retrieval

The existing Muse Editorial path has no native live web search. This PR adds a small operator-only retrieval module, **not** a new model stage and not automatic Editor input. An authenticated catalog operator can submit 1–3 HTTPS URLs from explicitly configured `RESEARCH_SOURCE_ORIGINS` to `POST /api/operator/catalog/research` with `{query,urls,quote?}`. The route requires existing operator Bearer authorization and `CULTURAL_RESEARCH_ENABLED=true`; both variables are absent/default-off in this PR. Cross-disciplinary use comes from the selected approved origins and query, not a fashion-specific taxonomy. No new provider credentials or schema migration are required.

Requests reject non-allowlisted origins, IP literals, credentials, redirects, non-text responses and bodies over 128 KiB. Output includes URL, origin, retrieval time, SHA-256, bounded excerpt, query relevance and explicit `verification: pending`. Duplicate content is collapsed by hash. Exact quotation matching is only a text-presence check; it does **not** verify author, work, date, public-domain status, quotation rights or claim accuracy. These remain operator review tasks before any source may be included in an editorial evidence pack. The module currently uses a 24-hour private Worker cache when available; no automatic publication or AI call occurs.

This is a working evidence-collection slice, not a general web search engine. It cannot discover URLs from a topic alone and does not establish brand facts or literary provenance automatically. The next separately approved increment should provide reviewed source records with attribution, publication date, rights/quotation status and cited claim spans; only approved records should reach Chief Editor, Reviewer and Revision. A reliable search provider, its quotas and price, and stronger extraction for complex HTML must be evaluated before enabling broad public research. Emergency rollback is `CULTURAL_RESEARCH_ENABLED=false`; the existing Editorial API is unaffected.
