All paid calls share the existing `magazine-v1` Durable Object and its current standard/demo caps. Per-IP cooldown may slow operator steps; there is no bypass. Reservation is before each call, and failed, timed-out or rejected steps may consume the reserved unit. No limit is raised by this PR. Long-form is a private draft; it cannot publish. `CULTURAL_INTELLIGENCE_V3_ENABLED`, `CULTURAL_RESEARCH_PLANNER_ENABLED`, `CULTURAL_RELATIONSHIP_AI_ENABLED` and `CULTURAL_LONGFORM_ENABLED` all remain false in source-controlled Wrangler configuration. An operator must configure `RESEARCH_SOURCE_ORIGINS` before retrieval and confirm provider quota, D1 migration `0006_longform_jobs.sql`, and R2/budget bindings before any activation. Do not assume a Dashboard variable survives the Git deployment: read back the effective flags and bindings after deployment.

Safe rollout is: merge only after review; deploy with all new flags false; verify existing Editorial, Silver Field and Object Discovery behavior; confirm migration state before enabling private articles; approve source origins and exact versions; enable one operator capability at a time only with owner authorization; run a bounded paid acceptance separately. Roll back by setting the four V3 flags false and verifying runtime readback. This preserves existing D1, R2 and DO histories, private evidence packs, and the V2.1 fallback. Revoked publication or cultural review must remain excluded on the next read. A source citation proves identity, not factual truth or quotation rights.
