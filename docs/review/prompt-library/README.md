# Discover prompt library visual review

The approved Discover composition remains the baseline. Only the headline, central sentence interaction, prompt position, and suggestion row changed. The five original editorial photographs, their frames and positions, orbital SVG, sphere, wordmark, consent, and submit behavior remain in the same component.

The editable sentence occupies space formerly used by the static headline and shifts the prompt field downward. The five discovery directions replace four static suggestion cards. The reference's original “What are you curious about?” title and one-line suggestion row therefore differ intentionally. The original photographic composition and HUD geometry are unchanged. At narrow widths, sentence text wraps and the five direction pills may use two rows; they remain inside the Discover stage and do not obscure the prompt or consent control.

Each choice updates the existing prompt state. The main text area still accepts an entirely custom prompt. Consent remains optional and is reset when a phrase changes. The existing editorial request, validation, budget controls, and deterministic fallback are unchanged. Automated browser tests cover phrase selection, custom words, Surprise me, manual prompt entry, submission, mobile keyboard interaction, and reduced motion.
